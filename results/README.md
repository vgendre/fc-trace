# Reference results

This directory contains small reference JSON outputs associated with the
camera-ready controlled evaluation:

- `controlled_evaluation_kernel_6.19.14.json` records the FC-Trace results for the five
  controlled scenarios used for the paper's primary metrics.
- `simulation_example.json` is a no-root simulation example and is not a
  real-image accuracy result.

Additional measured outputs and full provenance belong with the versioned
dataset and research-support artifacts, not with this code-only repository.
New experiment outputs should be written to temporary paths or a separate
results package rather than overwriting these reference files.
