# Reproducibility data

This directory contains only small, paper-relevant reproducibility metadata.
It does not contain raw disk images.

- `ground_truth/` contains the operation-level ledgers for controlled
  scenarios S1--S5.
- `raw_images/SHA256SUMS.txt` records checksums for the corresponding raw
  images in the versioned dataset deposit.

The five controlled raw images and their complete provenance are published at
[Zenodo DOI 10.5281/zenodo.21807669](https://doi.org/10.5281/zenodo.21807669).
Regenerated images are new validation runs and may have different inode
allocation, offsets, timestamps, and checksums.
